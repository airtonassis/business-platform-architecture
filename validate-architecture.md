---

Use o subagente `architecture-validator` para validar o domínio: $ARGUMENTS

Se nenhum domínio for informado como argumento, pergunte qual domínio validar antes de
prosseguir — não valide todos de uma vez sem confirmação, já que cada relatório deve
ser lido com atenção.
